# 远程招聘网站逐条核查

## 场景

很多人会收藏一份很长的「远程工作网站」清单，真正投递时才发现：站点改了定位、链接失效，或写着 Remote 却只招美国、要求与美国东部时间重叠。这一条记录的是：从公开的远程工作汇总清单出发，用人在澳洲、需要接受澳洲或亚太时区（UTC+11）的标准，逐条核对这些网站当天能不能打开、还适不适合当作远程招聘入口。

核对中国是 2026-11-21（Australia/Sydney）。没有注册，也没有投递。公开或使用前请再点开链接确认。

依据的汇总清单是 [awesome-remote-job](https://github.com/lukasz-madon/awesome-remote-job)。它是目录，不是「上了就能找到适合你的工作」的保证。仓库里写「上百个招聘网站」时，应以该仓库当时实际列出的数量为准，不必把宣传数字当真。

## 用什么工具

- 浏览器，逐条打开，看页面是否可访问、岗位能否筛到澳洲、亚太或 Worldwide
- 可选：对话工具，只用来整理「这个站点今天还是否像招聘板」，不要让它根据记忆判断某个站点是否还存在

## 具体步骤

1. 先确定你的硬条件。例如：必须接受澳洲或亚太时区；岗位类型偏销售、客户成功、进出口或供应链协调时，不要把纯工程站点当主场。
2. 打开汇总清单，先看有没有明确的 Asia-Pacific、Australia、Worldwide、Work from anywhere 分类。
3. 用网页实际打开，不凭仓库里的旧描述做决定。记录：能否打开、是不是仍在招人、远程是否限特定国家、要不要付费才能查看或申请。
4. 先用 Australia、Asia-Pacific、Worldwide 这类筛选，再打开职位看「可工作国家」和开会时区。
5. 本地或混合办公岗位，仍应同时看 Seek、LinkedIn 等澳洲常用站点。全球远程清单几乎不能替代它们。
6. 搜中文或中英双语岗位时，可加关键词 Mandarin、Chinese-speaking、APAC、Greater China。专门的中澳双语远程站，在那次核查里几乎没有出现。
7. 已经变成发薪或雇主雇佣产品、招聘页 404、或首页大量 On-site 岗位的站点，从「随地远程招聘板」名单里拿掉。

## 可复制提示词或配置

### 2026-11-21 核查时，对澳洲或亚太更值得优先看的

- [Jobspresso Asia-Pacific](https://jobspresso.co/remote-jobs-asia-pacific/) 和 [Worldwide](https://jobspresso.co/remote-jobs-worldwide/)：有亚太和全球分类，销售、客户成功也有专页，岗位会标明能从哪些国家上班。接受澳洲时区的岗位要用 APAC 或 Worldwide 筛选，销售总列表里美国岗很多。

同一天核查里还看过一批站点，它们能打开，但更偏美国、北美、欧洲、拉美，或偏工程与设计。对「人在澳洲、做销售或供应链」来说，不应默认当作主场。使用前仍要看该岗位是否接受澳洲时区。这类例子包括 Power to Fly、HigherEdJobs、若干欧洲开发岗位站、拉美远程站，以及 AI 开发或四天工作制等专题板。

[Daily Remote](https://dailyremote.com/) 当时可以打开，但说明里写了要付费才能查看和申请，性价比需你自己判断。[UN Talent](https://untalent.org/jobs/home-based) 能筛在家办公职位，门槛高、机会少，当作偶尔看看即可。

### 同一天核查时，已不宜当作「随地远程招聘板」的

- [Slasify](https://slasify.com/)：当时已变成雇主雇佣或发薪产品站，招聘页返回 404
- [Real Jobs From Anywhere](https://realjobsfromanywhere.com/)：首页销售列表里出现 On-site 岗位，不能当地点不限的站点用
- 原清单里若把 devtooljobs 的链接写成少了冒号的地址，应以 [https://devtooljobs.com/](https://devtooljobs.com/) 为准再核
- Remote Jobs Club 当时访问证书或服务器异常，不宜依赖

你自己复检时，可用下面这段整理记录。它不能判断站点是否还存在。

```
我在核对这些远程招聘网站是否还适合「人在澳洲、需要接受亚太时区」的求职。请根据我粘贴的、当天打开页面后的笔记，整理成三列：仍可作为远程招聘入口、需要付费或限制很多、已不宜当作随地远程招聘板。不要补充我没有打开过的网站，不要编岗位数量，不要判断我该不该申请。
我的笔记：
【站点名、网址、打开日期、是否能打开、远程是否限国家、是否要付费、有没有看到接受澳洲或亚太的岗位】
```

## 注意事项

- 链接和产品定位会变。这份名单的有效期从核对中国算起，不能当成长期目录。
- 「Remote」不等于可以在澳洲上班。
- 本条不是内推，也没有申请结果或录用数据。
- 不要在公开仓库里写你的真实住址、现雇主或正在进行的申请。
