# 一个人撑店，这些岗位我先交给 AI

作者：店长 AI 笔记（匿名）。在澳洲生活近 20 年，做过物流、开过店，现在做中澳贸易。

本仓库只在本地起草，尚未公开。公开时请用一个**新的匿名 GitHub 账号**，不要用任何能搜到真实身份的旧账号。公开前请先看文末「公开前必做」，不要把 `EVIDENCE.md` 或 `LAUNCH.md` 上传到 GitHub。

建议仓库名：`one-person-shop-ai-staff`。页面大标题用上面这句中文。副标题可用下面这句承诺。Excel 表格和 n8n 工作流与文档一并公开，见 [`tools/`](tools/README.md)。

## 一句话承诺

一份有步骤、有提示词、写明「已跑过还是还没跑过」的小生意 AI 岗位清单。只出草稿，发送键由你来按。

## 写给谁

- 在澳洲（或同样要处理英文询盘、账单、评论）一个人撑店、兼做批发或进出口的人
- 不想收藏空目录，想复制提示词或表格就能试的人
- 可以接受「先在示例数据上跑通，再换成自己的价目表和文件」

不是写给想全自动发帖、自动报价、自动回复差评的人。

## 怎么用

1. 先看目录，从你这周真正会碰到的一件事开始，不要一次装全套。
2. 打开对应条目，按「场景 → 工具 → 步骤 → 提示词或配置」做。示例文件在 [`tools/`](tools/README.md)。
3. 看条目末尾的「真实程度」。写了「已实测」的，表示我或助手已经用示例或本机演示跑过；写了限制条件的，不要理解成已经接到真实客户或真实店铺后台。
4. 发出去的邮件、报价、评论、社媒私信，一律自己看过再点发送。
5. 涉及政府机构、关税、GST、食品进口、劳动合同的内容，以官网和专业顾问为准。本仓库不是法律、税务或移民建议。

## 几条红线

- 不自动发送邮件、报价、评论或社媒回复。
- 不让 AI 编价格、库存、交期、营业时间或官方费率。价目表没有的，写「需你确认」。原文没写的，写「原文没写」。
- 不把真实客户邮件、真实价目表、店门口实拍或可识别的店铺资料上传到公开仓库。
- 不接任何「帮你自动发帖、自动登录社交账号」的工具。
