# 给小店做一条欢迎宠物的短视频草稿

## 场景

一家澳洲乡镇小咖啡馆，希望告诉来郊游的人：这里欢迎带狗的客人。店主没有现成的拍摄团队，也不想在影片里出镜。这一条记录的是一次「先做成片草稿，再由店主补地址和营业时间、自己发布」的做法。

公开说明里只讲方法。不要上传店门口实拍、招牌特写、成片文件或店铺账号。

## 用什么工具

- 用于出分镜和插画的图像或视频工具（具体选用哪一家，以你当时能用的为准）
- 剪辑或组装脚本，把分镜、口播和字幕合成竖版短视频
- 店主确认过的事实：是否真的欢迎狗狗、水碗或小零食放在哪里、室内能不能进。没有确认，就不要写成广告词
- 片尾需要的地址和营业时间，必须店主提供原文，不能自己检索或编造

## 具体步骤

1. 先向店主核实宠物相关规则，只写他们承认的部分。例如：是否欢迎狗狗、是户外还是室内、有没有水碗。拿不准的句子删掉。
2. 写一条很短的脚本，只讲一件事。不要在同一条里塞菜单、促销和完整地址。地址和营业时间放在片尾，等店主给原文再叠字。
3. 用插画或绘本风格出分镜，避免把真实人脸、真实顾客或清晰招牌做进公开素材库。店门口如果有实拍，只作为店主自己留存的参考，不要放进公开仓库。
4. 合成竖版成片草稿（常见为 1080×1920）。口播和画面长度对不上时，以不挡住关键画面为准，宁可稍长短一点。
5. 片尾先留空位给地址和营业时间。这两项空着，也不要自己上网补。店主把准确原文发来后，只改文字层，不必重画全部画面。
6. 文案草稿同样交给店主改。发布账号、发布平台和发布时间由店主决定。不要代发，也不要为了赶发布时间编营业时间。
7. 成片在店主确认之前，只算草稿。

下面是一条可以改写的文案骨架，里面没有任何真实店名、地名或账号。方括号必须换成店主确认过的内容，或直接删掉。

```
在不少乡镇咖啡馆，先推门的其实是狗。

【店名或就写「这家店」】会先问狗的名字。

门口有水碗。【如果店主确认有小零食，再写这一句；没有就删。】

带狗出来玩的话，可以先收藏，下次用得上。

也可以转给平时牵着绳子的那个人。
```

片尾只放：店主提供的地址、店主提供的营业时间、店主指定的账号。缺一项就留空，不要补。

## 可复制提示词或配置

写脚本时可以用这一段。它不得发明店里没有的设施。

```
你为一家澳洲小咖啡馆写一条不超过 30 秒的竖版短视频口播草稿，欢迎带狗的客人。只用我核实过的事实。我没写的设施、营业时间、地址、价格和促销，一律不要出现。不要出镜要求，不要写真实人名。语气平、短句，不要夸张广告腔。先给口播，再给分镜要点，最后给片尾需要店主填写的空位清单。
已核实的事实：
【例如：户外座位欢迎狗狗；门口有水碗。室内政策未确认，则不要写室内欢迎。】
```

## 注意事项

- 公开仓库只保留方法，不放成片、封面、店门口照片或带有招牌的画面。
- 没有店主原文，就不要在片尾或字幕里写地址和营业时间。
- 这条方法演示的是「欢迎宠物」这一类宣传，不是已经验证过播放量或带客效果的方案。不要根据一次未发布的草稿去承诺能吸引多少客人。
- 若以后在店铺账号发布同一条视频，请注意：仓库里的方法描述不要写到能让人对应到那家店的程度。
