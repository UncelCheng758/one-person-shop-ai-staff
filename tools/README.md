# 附带文件说明

这里的文件都是教学示例或可改过再用的工具，不是真实客户资料，也不是报价。

| 路径 | 是什么 | 注意 |
| --- | --- | --- |
| `选品与算账工具箱_v1.xlsx` | 三张工作表：选品 10 维度打分、落地成本与保本 ROAS、工厂询盘与打样核对，外加使用说明 | 黄色格自己填。表里现成的产品名、价格、工厂都是示例。关税和 GST 必须按官方口径改，不要用示例税率下单。 |
| `n8n/inquiry-to-sheet.json` | 把一封询价邮件抽字段、写入表格、生成确认草稿的 n8n 工作流 | 在本机 n8n 里导入。默认写入 `./output/`。不要接真实邮箱发送权限。演示输入是虚构的咖啡店询价。 |
| `samples/示例电费账单.txt` | 教学用虚构电费单 | 请勿付款，请勿把付款码输入网银。 |
| `samples/示例询盘与价目表.txt` | 教学用虚构家居询盘和价目表 | 请勿发信、请勿下单。 |
| `samples/示例询价表格.csv`、`samples/示例询价确认草稿.txt` | 用上面工作流跑出来的一次演示结果 | 没有报价数字，也没有真的发信。 |

不要把真实客户邮件、真实价目表、店门口实拍或带招牌的成片放进这个文件夹。
