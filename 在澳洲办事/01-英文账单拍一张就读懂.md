# 英文账单拍一张就读懂

## 场景

在澳洲收到水电费、网络费一类英文账单时，先要看清：是谁寄的、要你付多少、哪一天到期、晚付会怎样、有没有「估算抄表」这类需要留意的词。然后再决定自己登录官网核对，或写一封询问邮件。AI 只做解读和草稿，不代替你付款，也不构成缴费建议。

## 用什么工具

- 能接受照片或文本的对话工具
- 练习材料：[`tools/samples/示例电费账单.txt`](../tools/samples/示例电费账单.txt)（虚构账单，请勿付款）

## 具体步骤

1. 如果是真实账单，先遮掉姓名、地址、账号、付款参考号，再交给 AI。练习时用示例文件即可。
2. 使用下面的提示词。要求它：原文没写的就写「原文没写」，不要编数字，也不要补充原文没有的罚则。
3. 看完解读后，自己在浏览器输入该机构的官网地址，登录账户核对金额和到期日。不要点信件、短信或邮件里的链接。电话也先到官网查，不要先拨信上的号码。
4. 把到期日和折扣价（如果有）抄到日历里。
5. 若需要向对方询问，使用 AI 起草的短英文邮件，由你核对后自己发送。示例账单对应的询问信，不要真的发出。
6. 付款前再核对该笔付款的户名和参考号是否与官网账户一致。

按示例账单跑出来的关键结果如下，全部来自那份虚构原文：

- 寄件方是 Example Energy Pty Ltd，这是教学示例，不是真实供电商
- 账单周期：2026-08-12 至 2026-11-09（90 天）
- 开票日：2026-11-10 星期二
- 到期日：2026-12-01 星期二
- 应付总额：283.80 澳元（含 GST）；到期前付清为 269.60 澳元（含 14.20 澳元按时付款折扣）
- 原文写明这是估算抄表（estimated meter reading），实际读数出来后金额可能调整
- 原文没写滞纳金、罚款、利息或停电
- 预定的下次抄表窗口：2027-02-08 至 2027-02-14

## 可复制提示词或配置

```
我拍了一张在澳洲收到的英文账单或信件。请用中文按下面格式回答。原文没写的就写「原文没写」，不要编数字，也不要补充原文没有的罚则。

1. 寄件方是谁？一句话说明这份文件要我做什么。
2. 列出金额、账单周期、开票日和到期日。日期写成 年-月-日，并标出星期几。
3. 根据原文，不按时会怎样。原文没写滞纳金或罚款，就明确写没写。
4. 原文里有没有这些需要留意的词：estimated / 估算读数、discount / 折扣、overdue / 欠费、penalty / 罚款、interest / 利息。有就原句摘出来。
5. 建议我按什么顺序做下一步。涉及付款、登录账户或申诉时，提醒我自己在浏览器输入官网地址，不要点信里或邮件里的链接；电话也先到官网查，不要先拨信上的号码。
6. 这份文件看起来像不像正规文件？写正常之处和疑点。若我已说明这是示例文件，请直接标明。
7. 如果我需要向对方问一件事，请起草一封短英文邮件，不超过 120 词，语气礼貌，并附中文对照。

请把关键金额和截止日期单独列在最后，方便我抄到日历里。
```

## 注意事项

- 示例文件上的公司名、ABN、NMI、BPAY 编码全部是占位符。请勿付款，请勿把这些付款码输入网银。
- 这不是法律、税务或缴费建议。套餐比较可到 energymadeeasy.gov.au 等官方站点，ABN 可到 ABR 查询。是否正规，最终以官方渠道为准。
- 真实账单不要把未遮挡的个人信息贴进公开聊天或公开仓库。

## 真实程度（已实测，有范围）

已用这份虚构电费单，按上面的提示词逐条做出解读，并起草了一封询问估算抄表如何调整的中英对照邮件。这不是真实供电商发出的账单，也没有用某张真实家庭账单做公开演示。
